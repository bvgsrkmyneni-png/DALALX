# DALALX — Virtual Stock Trading Platform

A full-stack educational virtual stock trading platform developed using React, Node.js, Express.js, and PostgreSQL.

DALALX allows users to experience stock trading using virtual money without the risk of real financial loss.

## Project Objective

The objective of DALALX is to provide a simple and interactive platform where users can learn stock trading concepts, monitor stock prices, manage virtual investments, and understand profit and loss.

## Key Features

- User Registration and Login
- User and Admin Roles
- Interactive Trading Dashboard
- Market Watch and Stock Price Monitoring
- Virtual Stock Buying and Selling
- Portfolio and Holdings Management
- Profit and Loss Tracking Based on Purchase Price
- Available Funds and Account Value
- Transaction and Order History
- Admin Dashboard and Stock Management
- Light and Dark Themes
- Responsive User Interface

## Installation and Setup

### Requirements

- Node.js and npm
- PostgreSQL
- Git

### Clone the Repository

    git clone https://github.com/bvgsrkmyneni-png/DALALX.git
    cd DALALX

### Install Dependencies

Backend:

    cd backend
    npm install

Frontend:

    cd ../frontend
    npm install

### Configure Database

Create and configure the PostgreSQL database and set the required backend environment variables.

Keep database passwords and secret keys private.

### Run the Application

Start the backend using the command configured in `backend/package.json`.

Start the frontend:

    cd frontend
    npm run dev

Open the local URL displayed by Vite in your browser.
