# DALALX — Virtual Stock Trading Platform

DALALX is an educational virtual stock trading platform where users can practice buying and selling stocks using virtual money.

## Project Team

**Developed By:**
- M.Bvgs Krishna
- Udumula Avinash

## Features

- User Registration and Login
- User and Admin Dashboard
- Market Watch
- Virtual Stock Buying and Selling
- Portfolio and Holdings Management
- Profit and Loss Tracking
- Transaction History
- Admin Stock Management
- Light and Dark Themes

## Technologies Used

- Frontend: React.js, Vite, CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL
